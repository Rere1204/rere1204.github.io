♡ Project Overview

This project explores climate data quality using Python, focusing on identifying missing observations and evaluating data completeness.

The goal is to understand data reliability before performing climate analysis.

♡ Methodology

1. Missing Value Detection

Identify missing observations, including the missing-value code 9999 where used in the source dataset.

2. Data Completeness

Completeness (%) = (Valid Observations / Expected Observations) x 100

3. Data Visualization

Summarize valid and missing observations through charts and tables.

♡ Python Implementation

Example: identifying missing values in an observation column. 

import pandas as pd

# Example dataset
data = [25, 27, 9999, 29, None, 30]

df = pd.DataFrame({"value": data})

# Identify valid observations
valid = (
    df["value"].notna()
    & (df["value"] != 9999)
)

# Calculate completeness
total = len(df)
n_valid = valid.sum()

percentage = (n_valid / total) * 100

print("Valid observations:", n_valid)
print("Completeness:", percentage)

This is an illustrative example. The final analysis will use an authorized dataset and its observation schedule to determine expected records.
